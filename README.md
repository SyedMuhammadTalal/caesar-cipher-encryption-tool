
# Caesar Cipher Encryption-Decryption Tool :

## Project Overview
This project is a Python-based encryption and decryption tool that uses the Caesar Cipher algorithm. It allows users to securely encrypt and decrypt messages using a shift-based logic while maintaining a structured history log system.

## Features
- Encrypt and Decrypt text using Caesar Cipher
- Input validation (no numbers or empty input allowed)
- Menu-driven interface for easy interaction
- History logging system for both encryption and decryption
- Organized project structure (Source Code, History, Documentation)
- UTF-8 file handling for safe and reliable storage
- Dynamic path handling using OS module

## Learning Outcomes
- Basic cryptography concepts
- File handling in Python
- OS module for directory management
- Input validation techniques
- Git & GitHub workflow

## Project Structure
Source Code → main application logic  
History → stores encryption & decryption logs  
Documentation → project documentation files
